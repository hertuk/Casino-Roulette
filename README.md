🎰 Casino Roulette – Симулятор европейской рулетки

**Полнофункциональная игра в рулетку** на **7 языках программирования**.  
Реализована классическая европейская рулетка с одним зеро, множеством видов ставок, ведением баланса, историей и статистикой.

---

## 🎲 Возможности (общие для всех версий)

- 🟢 **Европейская рулетка** (одно зеро, 37 номеров).
- 💰 **Стартовый баланс** – 1000 фишек.
- 🎯 **Виды ставок**:
  - Прямая (на номер) – выплата 35:1
  - Цвет (красное/чёрное) – 1:1
  - Чёт/Нечет – 1:1
  - Большое (19–36) / Малое (1–18) – 1:1
  - Дюжины (1-12, 13-24, 25-36) – 2:1
  - Колонки (по вертикали) – 2:1
- 📊 **Статистика** – общее количество спинов, выигрышей, процент побед.
- 💾 **Сохранение и загрузка** состояния (баланс, история) в файл.
- 🎨 **Цветной вывод** в консоли для наглядности.
- 🤖 **Режим автоигры** – компьютер делает ставки по заданной стратегии.
- 📈 **График баланса** (в некоторых версиях) – визуализация изменения капитала.

## 📦 Зависимости

- **Python**: стандартная библиотека + `colorama` (опционально, для цвета).
- **JavaScript**: Node.js, используется `readline` и `fs`.
- **Java**: стандартный JDK, без внешних библиотек (JSON парсится вручную).
- **C++**: требуется библиотека **nlohmann/json** (скачать `json.hpp`) или установить через менеджер пакетов.
- **C#**: .NET SDK, использует `System.Text.Json`.
- **Go**: только стандартная библиотека.
- **Rust**: зависимости в `Cargo.toml`: `rand = "0.8"`, `serde = { version = "1.0", features = ["derive"] }`, `serde_json = "1.0"`.

## 🛠️ Продвинутые фичи по языкам

- **Python**: график баланса с помощью `matplotlib` (опционально), поддержка аргументов командной строки для автоигры.
- **JavaScript**: асинхронный ввод/вывод, красивые эмодзи.
- **Java**: использование `enum` для типов ставок, паттерн Стратегия для автоигры.
- **C++**: использование `std::variant` для разных типов ставок, умные указатели.
- **C#**: LINQ для анализа истории, события на каждый спин.
- **Go**: горутины для анимации спина (имитация задержки).
- **Rust**: мощная система типов для ставок, итераторы, обработка ошибок через `Result`.
